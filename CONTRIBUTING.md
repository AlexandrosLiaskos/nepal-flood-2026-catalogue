# Contributing corrections and candidate information

Corrections to published catalogue information may be sent to [evelpidou@geol.uoa.gr](mailto:evelpidou@geol.uoa.gr). Please identify the public record or asset, the field concerned, and an authoritative public source supporting the correction.

Resources can be nominated through the page [Nominate](https://evelpidou.nkua.cloud/Nepal-Flood-2026-Catalogue/nominate/) of the site, which prepares an email message to the review team. A nomination does not become an included resource automatically; it must be assessed against the review eligibility criteria.

Contributions must preserve these boundaries:

- A candidate under review is not an included resource.
- A listed asset is not a separate review resource unless independently established as one.
- Endpoint availability is not evidence of an open licence or redistribution permission.
- Unknown information is recorded as not stated, not verified, conflicting, or not applicable; it is not inferred.
- Credentials, private notes, reviewer identities, local paths, and copyrighted source exports do not belong in public catalogue files.

Do not submit or mirror third-party asset bodies unless their licence expressly permits redistribution.

## Code

Changes to the code of the site are welcome through pull requests to this repository. The branch `main`
receives a change only through a pull request whose checks have passed. Code contributions are accepted
under the MIT License, and contributions to the catalogue text under the Creative Commons Attribution 4.0
International licence (see [LICENSE.md](LICENSE.md)).

- Run the checks listed in [README.md](README.md) before opening a pull request.
- Do not commit the records of the catalogue, the search reports, institutional marks or third-party
  photographs; `.gitignore` lists them.
- Write the subject of a commit in the imperative, in at most 72 characters, and describe one change in
  each commit.
- Record every notable change in [CHANGELOG.md](CHANGELOG.md).
